# 导演知识手册 · 漫剧脚本与分镜图制作

一份把编剧理论与视听语法压缩进漫剧短形态的实用汇编。从钩子设计到镜头语言，从故事结构到分镜流程——涵盖 13 个知识模块。

## 内容

- `director-knowledge-compendium.html` — 完整知识手册（13 个模块，深色科技感主题）
- `share-cards.html` — 11 张竖版分享卡片（4:5 比例，适合截图分享到社交媒体）
